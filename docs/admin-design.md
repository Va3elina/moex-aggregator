# Дизайн админки — правила

Правила для `/admin/*`. Они существуют, чтобы не переделывать одно и то же
по третьему разу: каждое нарушение здесь — это то, за что уже прилетало.

Основа — copy-paste компоненты [Tremor](https://tremor.so) на чистом Tailwind
(`frontend/src/components/admin/ui/`). Tremor даёт структуру и поведение,
внешний вид берётся из наших editorial-токенов (`index.css`) — своих цветовых
токенов Tremor не приносит, и приносить не должен.

---

## 1. Иерархия: ровно три уровня

На экране в любой момент три веса, не больше:

| уровень | что это | как выглядит |
|---|---|---|
| **1. Ответ** | 3–6 чисел, ради которых заходят | крупная цифра, без рамки, на фоне страницы |
| **2. Поддержка** | графики, списки, разрезы | карточка: фон `--bg-secondary`, рамка 1px |
| **3. Детали** | таблицы, ленты, длинные списки | без собственной рамки, внутри карточки |

Нельзя: одинаковая рамка на всех блоках. Когда обведено всё — не выделено ничто.
Рамка 2px — только у элемента, с которым сейчас работают (активный фильтр,
выбранная строка).

## 2. Контролы: не больше четырёх на экран

Четыре — это весь бюджет страницы, а не одного блока. Шапка периода (период,
сегмент, устройство) — уже три.

Что делать с остальным:
- фильтры второго порядка → внутрь блока, к которому относятся, и не больше одного;
- взаимоисключающие наборы → один `Dropdown`, а не ряд кнопок;
- всё сверх бюджета → на отдельную вкладку или под «показать ещё».

Нельзя: ряд из шести кнопок-срезов и следом двенадцать чипов. Это было — и это
главная причина, по которой страницу пришлось откатить.

## 3. Один акцент

`--accent` (#FF5C2B) — один на экран, на самом важном. Всё остальное —
нейтрали (`--text-primary/secondary/muted`).

Семантика (`--success`, `--warning`, `--danger`) — отдельная шкала: только про
состояние данных (растёт/падает, оплачено/просрочено), никогда как украшение и
никогда вместо акцента.

Нельзя: подсвечивать акцентом каждую вторую плашку. Нельзя красить строки
таблицы в семантические цвета — только бейдж внутри строки.

## 4. Размеры: шкала, а не произвольные числа

Отступы — только `--sp-*` (кратно 4). Между блоками 24px, внутри карточки 16px,
между строками списка 8px.

Шрифты — только:
- 11px моно, uppercase, `letter-spacing: .08em` — подписи колонок и метрик;
- 13px — текст таблиц;
- 14px — основной;
- 20–28px моно — цифры первого уровня.

Цифры всегда `font-variant-numeric: tabular-nums` и `'IBM Plex Mono'` — иначе
колонки не выравниваются.

## 5. Плотность таблиц

Строка — 40px (8px вертикальный отступ). Разделители — `1px` в 60% прозрачности,
не сплошной чёрный. Первая колонка — кто/что, последняя — действие. Числовые
колонки выровнены вправо.

Таблица на странице **одна**. Две таблицы, отвечающие на похожий вопрос, — это
не выбор для пользователя, это шум: он не понимает, в какую смотреть.

## 6. Движение

Есть ровно три анимации, все на `cubic-bezier(.2,0,0,1)`:

| что | длительность | когда |
|---|---|---|
| появление данных | 200ms fade + 4px вверх | блок получил данные |
| смена числа | 350ms счётчиком | значение изменилось (`useTweened`) |
| затемнение при перезагрузке | 120ms, с задержкой 250ms | данные обновляются (`useDelayedFlag`) |

Задержка в 250ms обязательна: без неё быстрый ответ даёт мигание, которое
читается как баг.

Нельзя: анимировать появление каждой строки таблицы, двигать блоки при
наведении, крутить спиннеры там, где хватает затемнения.
Всё движение отключается под `prefers-reduced-motion`.

## 7. Состояния

У каждого блока четыре состояния, и все четыре пишутся сразу:
загрузка (`Skeleton` в размер будущего контента), пусто (одна фраза, что
именно пусто и почему), ошибка (что сломалось), данные.

«Пусто» и «ошибка» — разные вещи: «Никого не нашли» и «Не удалось загрузить»
нельзя показывать одним текстом.

## 8. Слова

Заголовок блока — вопрос или существительное, не термин из кода: «Что смотрят»,
а не «Top pages». Подпись под цифрой объясняет, как она посчитана, а не
повторяет заголовок. Числа — с разделителем разрядов (`toLocaleString('ru-RU')`).

## Проверка перед PR

- [ ] Контролов на экране не больше четырёх
- [ ] Три уровня веса, рамка 2px только у активного
- [ ] Акцент один
- [ ] Отступы и кегли — со шкалы
- [ ] Таблица одна
- [ ] Четыре состояния у каждого блока
- [ ] Анимации только из таблицы в п.6
