Безопасность

SSH

Ключ-only (PasswordAuthentication no). iptables whitelist по IP Вадима. fail2ban активен.

TLS

Let's Encrypt, auto-renew. HSTS включён.

PostgreSQL

Bind 127.0.0.1:5432, не наружу. Внутри docker network доступен по db:5432.

Auth

JWT + refresh_tokens в БД. OAuth: Google, VK, Yandex.

Источники данных

Внешние API и сайты, откуда тянется всё содержимое платформы.

используется ISS MOEX

URL: https://iss.moex.com/iss/ · публичный, без ключей

Что: дневные свечи, индексы, веса IMOEX, 5-мин свечи. ~1000 req/час rate limit.

Скрипты: Candles/fetch_candles_*_realtime.py

Таблицы: candles, index_data, instruments, dividends

используется Algopack (apim.moex.com)

URL: https://apim.moex.com/ · JWT в ALGOPACK_API_KEY

Что: 5-минутные свечи, OI фьючерсов

Скрипты: OI/fetch_oi_5min_realtime.py

Таблицы: open_interest, candles (5min)

используется ЦБ РФ

URL: cbr.ru/vfs/statistics/credit_statistics/monetary_agg.xlsx

Что: M2, CPI/ИПЦ · XLSX (openpyxl)

Гитча: User-Agent обязателен иначе блочат. Строка 14 = M2.

Скрипт: Macro/fetch_macro_realtime.py

используется SmartLab (парсинг)

Что: полная капитализация рынка (MARKET_CAP_TOTAL) через HTML scraping

Скрипт: Macro/fetch_market_cap.py

используется World Bank

URL: api.worldbank.org/v2/country/RUS/indicator/{CODE}?format=json

Что: годовой GDP, GFCF (в рублях, делить на 1e9 для млрд)

ручной импорт Росстат

URL: rosstat.gov.ru/storage/mediabank/

Что: квартальный ВВП, дефляторы, инвестиции. XLSX (нет API).

Гитчи: SSL не всегда валидный (отключать verify). Сноски в ячейках ("20222)3)" → regex \d{4}). Проверять 'IV' in period до 'I' in period, иначе всё станет Q1.

проверено ЕАЭС, FRED

ЕАЭС: квартальные инвестиции ЕАЭС стран. XLS (нужен xlrd, не openpyxl). Данные "нарастающим итогом" — пересчитывать.

FRED: SEASONALLY ADJUSTED — несовместимо с сырыми росстатовскими рядами для growth rate.

отклонено Cbonds, ЕМИСС, TradingEconomics

Cbonds — платная авторизация. ЕМИСС — капча. TradingEconomics / Investing / Seasonax — только как проверочный референс для верификации методологии.

Frontend деплой

# 1. Бампнуть CACHE_NAME в frontend/public/sw.js
# 2. Собрать локально
cd frontend && npm run build

# 3. Упаковать и загрузить
tar -czf /tmp/dist.tar.gz -C frontend/dist .
scp /tmp/dist.tar.gz root@103.88.243.232:/tmp/

# 4. На сервере — распаковать в контейнер
ssh root@103.88.243.232 '\
  cd /tmp && mkdir -p dist_new && tar -xzf dist.tar.gz -C dist_new && \
  docker cp dist_new/. frame-api-1:/app/frontend/dist/ && \
  rm -rf dist_new dist.tar.gz'
⚠ Путь внутри контейнера: /app/frontend/dist/, НЕ /app/static/.
⚠ Service Worker: каждый фронт-деплой — бампай CACHE_NAME в frontend/public/sw.js, иначе юзеры будут видеть кеш.
