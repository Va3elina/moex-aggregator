# Замер векторов на постах (05.09.2026)

Модель potion-multilingual-128M (model2vec, 256 измерений), 33 140 узлов, HNSW по косинусу.
Скрипт — `measure_vectors.py` в контейнере api через функции `api/routers/brain.py`.

## Якорь для новости без тикера: ближайшая компания по смыслу заголовка

118 кандидатов за 60 дней с известными тикерами; заголовок → `search?mode=meaning&kind=company`.

| Компания в топ-1 | в топ-3 | в топ-5 | Медиана запроса |
|---|---|---|---|
| 61 (51 %) | 71 (60 %) | 76 (64 %) | 4 мс |

## Похожие кандидаты

Среди десяти ближайших кандидатов доля с тем же тикером — в среднем 0.09: вектор заголовка тянет к теме (авиация, нефть, банки), а не к компании. Для «похожих поводов» это и нужно; для «той же компании» — структурные рёбра.

## Выводы

- Смысловой якорь работает как подсказка, не как истина: в половине случаев компания угадана с первого места, в двух третях — в пятёрке. Промахи — заголовки без названия компании («ПЕРВАЯ НЕФТЬ ВОСТОК ОЙЛА…» → энергетика).
- Правильное применение: новость без тикера → топ-5 компаний по смыслу → подтверждение по тикеру/названию в тексте (структурная проверка), не наоборот.
- «Похожие по смыслу» для узла — поиск прошлых поводов и соседних тем; рёбра из этого не строятся.
