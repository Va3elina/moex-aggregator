# Форвард-тест сессионных троек — предварительная регистрация

**Заморожено: 2026-07-28. Форвард начинается 2026-07-29.**

Этот файл написан ДО появления форвардных данных и закоммичен в git. История
коммита — доказательство, что критерии не подгонялись под результат. Если
что-то здесь меняется после даты заморозки, эксперимент считается
испорченным и начинается заново с новой датой.

---

## Зачем

На истории 2023-07 .. 2026-07 был перебран весь набор сессионных троек:
для каждой бумаги — все пары часов A→B внутри дня, все часы выхода C на
следующий день, оба направления (продолжение и разворот). Только для
Сургута это 26 100 вариантов; по девяти бумагам — свыше 200 тысяч.

Лучший вариант такого перебора **всегда** выглядит хорошо, даже если в
данных нет ничего кроме шума: в верхний 1% из 26 100 вариантов по
определению попадает 261 штука. Проверить находку на той же истории
невозможно в принципе — любая проверка использует те же данные, по которым
шёл отбор.

Проверено формальными методами (Deflated Sharpe Ratio, PBO/CSCV — см.
PROTOCOL.md, раздел 5): оценка надёжности 0.004 при необходимых 0.95,
вероятность переобучения 0.43 при допустимых 0.05. Это не приговор
стратегии — это утверждение, что **на имеющейся истории вопрос
неразрешим**.

Единственный оставшийся способ — данные, которых не существовало в момент
отбора.

## Что именно проверяется

**Не одна выбранная конфигурация, а вся сетка целиком.** Это принципиально:
если проверять только победителя, снова не с чем сравнивать. Проверяя все
варианты сразу, мы задаём вопрос, на который есть однозначный ответ:

> Сохраняют ли конфигурации, хорошие на истории, своё преимущество вперёд?

- Сохраняют → перебор нашёл настоящую структуру рынка.
- Не сохраняют, порядок вариантов перемешался случайно → перебор нашёл шум.

## Замороженные параметры

| параметр | значение |
|---|---|
| бумаги | SG, SS, AK, MN, PI, CC, SP, MC, CR (фьючерсы, непрерывный front-month) |
| сетка | все A<B в одном дне × все C на следующем × {продолжение, разворот} |
| слоты | получасовые; цена берётся в **КОНЦЕ** слота |
| набор слотов | фиксирован по baseline, на форварде не пересчитывается |
| порог сигнала | 0.1% |
| разрыв дат | сделка выбрасывается, если между днями больше 5 календарных дней |
| основные издержки | 0.05% туда-обратно |
| лестница издержек | 0 / 0.05 / 0.08 / 0.10 / 0.20% |
| минимум для выводов | 150 форвардных сделок |

Ничего из этого не подбирается по ходу. Лестница издержек зафиксирована
заранее именно потому, что в прошлом исследовании произвольный выбор
0.2% в одиночку переворачивал вывод.

## Главный критерий

Берём 100 конфигураций, лучших **на baseline**, и смотрим их результат
вперёд — против 2000 случайных наборов по 100 конфигураций в том же
периоде.

Случайный набор — это «что дала бы бумага сама по себе». Разница между
отобранным и случайным и есть ценность отбора, очищенная от дрейфа рынка.

| результат | вывод |
|---|---|
| надбавка > 0, перцентиль > 95 | отбор несёт информацию |
| надбавка ≈ 0 | перебор нашёл шум; выбранные часы — случайность |
| надбавка < 0 | подгонка: отобранные систематически хуже случайных |

Считается по каждой бумаге отдельно, итог — знаковый тест по девяти.

**Что ожидать.** На расщеплении истории (обучение — начало, проверка —
остаток) этот критерий даёт надбавку **+0.17 п.п. на сделку** в среднем,
плюс на всех девяти бумагах, перцентиль 100 против плацебо. Устойчиво:
44 ячейки из 45 положительны по пяти точкам разреза, и не зависит от
размера отбора (K = 20 / 100 / 500 дают то же). Форвард проверяет, дожил
ли этот эффект до данных, которых при отборе не существовало.

### Поправка №1 (28.07.2026, до появления любых форвардных данных)

Изначально главным критерием была ранговая корреляция «результат на
истории → результат вперёд». **Заменён.** Проверка на расщеплении истории
показала, что он засорён механикой: связь по волатильности 0.65–0.91, по
числу сделок 0.42–0.60. То есть критерий во многом мерил бы устойчивость
волатильности — величину, которая сохраняется тривиально и о качестве
отбора не говорит ничего. Ранговая связь остаётся во вторичных
наблюдениях, как справочная.

Поправка внесена до 2026-07-29 — форвардных данных на этот момент не
существовало, подогнать критерий под результат было физически не подо что.

## Вторичные наблюдения

1. **Именованная конфигурация** SG 19:30→20:30→15:00 разворот: сколько
   сделок, средняя доходность, 95% интервал, лестница издержек. Проверяется
   наравне со всеми, без привилегий.
2. **Перцентиль именованной** среди своей бумаги: было ~99, стало сколько.
   Падение к ~50 — прямая демонстрация «лучшей из 26 100».
3. **Контроль дрейфа**: доля всех конфигураций с плюсом. Если вперёд
   плюсуют почти все — это движение рынка, а не качество отбора, и любой
   положительный результат именованной ничего не значит.

## Правила остановки

- **Раньше 150 форвардных сделок выводов не делаем.** Смотреть динамику
  можно, менять спецификацию по увиденному — нет.
- Промежуточные просмотры не наказываются поправкой только потому, что не
  ведут к решениям. Как только по промежуточному результату принимается
  решение — эксперимент испорчен.
- **Что считается подтверждением:** надбавка отбора над случайным выбором
  положительна не менее чем на 7 бумагах из 9 (знаковый тест p < 0.05).
- **Что считается опровержением:** надбавка ≈ 0 или отрицательна при ≥150
  сделках.
- Промежуточный исход (надбавка есть, но именованная конфигурация не
  работает) читается как «структура есть, но конкретные часы были
  случайностью» — тогда осмысленно выбирать заново, уже на новых данных.

## Чего этот тест не покроет

- **Исполнимость.** В решающий получас у SG медиана 3 контракта за 5 минут,
  50% баров без движения. Форвард считается по ценам закрытия баров и
  проскальзывание не моделирует. Даже полное подтверждение не означает, что
  через это пролезет заметный капитал — тем более автоследование.
- **Смену режима рынка.** Год форварда — это один режим. Подтверждение в
  нём не переносится автоматически на другой.
