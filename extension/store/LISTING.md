## Подробное описание (Description)

```
Фрейм добавляет аналитические индикаторы Московской биржи прямо в веб-терминал
Т-Инвестиций — плавающими окнами поверх вашего рабочего пространства. Не нужно
переключаться между вкладками: график торгуется в терминале, а рядом — открытый
интерес, сезонность и потоки капитала.

🟠 Как пользоваться
1. Нажмите кнопку «F» в панели инструментов терминала (рядом с «Виджеты»).
2. Выберите индикатор из списка — откроется отдельное плавающее окно.
3. Перетаскивайте, меняйте размер, прилипайте к виджетам терминала. Откройте
   сколько угодно панелей одновременно.

📊 7 индикаторов (полный функционал, как на сайте)
• Открытый интерес — позиции физлиц и юрлиц по фьючерсам (режимы, таймфреймы,
  экспирации, чистая позиция)
• Сезонность — средние движения по дням недели/месяца и годовая сезонность
• Индикатор Баффетта — капитализация рынка к ВВП и к денежной массе M2
• Сила рынка — доля акций выше скользящих EMA (breadth)
• Фонды — приток и отток средств в БПИФ по категориям
• Потоки ЦБ — нетто-потоки участников (физлица, банки, нерезиденты, НФО)
• Сделки фондов — что покупают и продают управляющие компании

⚙️ Настройки у каждого индикатора
Шестерёнка в заголовке панели открывает все режимы, периоды и фильтры — выбор
актива, таймфрейм, режим расчёта и т.д.

🔒 Доступ
Индикаторы доступны подписчикам Pro сервиса Фрейм. Токен генерируется в личном
кабинете на таймфрейм.рф и вставляется в окно расширения. Без токена панели
показывают экран блокировки.

Расширение НЕ читает ваши сделки, позиции или баланс и не размещает заявки —
оно только показывает аналитику поверх страницы.

Сайт: https://таймфрейм.рф
Поддержка: см. контакты на сайте.
```

## Обоснование разрешений (Permissions justification)

> Web Store просит объяснить каждое разрешение. Вставляй в соответствующие поля.

**`storage`**
```
Хранит локально PRO-токен пользователя (для доступа к индикаторам) и раскладку
открытых панелей (позиции/размеры/тема), чтобы восстановить их при следующем
открытии терминала. Данные не покидают браузер.
```

**`declarativeNetRequest`**
```
Снимает заголовок Content-Security-Policy на страницах веб-терминала
Т-Инвестиций, чтобы внутри терминала мог отрисоваться iframe с индикатором
Фрейм (таймфрейм.рф), который иначе блокируется политикой CSP терминала.
Правило ограничено только URL терминала.
```

**Host permissions (`*.tbank.ru`, `*.tinkoff.ru`)**
```
Расширение работает только на страницах веб-терминала Т-Инвестиций
(tbank.ru/terminal, tinkoff.ru/invest-terminal). Доступ нужен, чтобы вставить
кнопку запуска и плавающие панели индикаторов в интерфейс терминала.
```

**Remote code: НЕТ.**
```
Весь исполняемый код расширения находится в пакете. Индикаторы загружаются как
веб-страница в iframe с собственного домена таймфрейм.рф (контент, не код в
контексте расширения). Расширение не использует eval и не подгружает скрипты
извне.
```

**Single purpose (одно назначение)**
```
Показывать аналитические индикаторы Фрейм плавающими панелями поверх
веб-терминала Т-Инвестиций.
```

| Тип данных | Собирается? | Что указать |

| Personally identifiable info | Нет | — |
| Financial / payment info | Нет | расширение НЕ читает сделки/позиции/баланс терминала |
| Location, Health, Web history | Нет | — |
| User activity | Нет | — |
| Website content | Нет* | content-script читает DOM терминала локально (кнопка/прилипание), но НИЧЕГО не передаёт и не сохраняет |

Три обязательных подтверждения (отметить все):
- ✅ Не продаём данные третьим лицам.
- ✅ Не используем данные для целей, не связанных с назначением расширения.
- ✅ Не используем данные для оценки кредитоспособности / займов.
