# extension/store — пакет для публикации

Всё для выкладки расширения «Фрейм» в Chrome Web Store (и каталог Яндекса).

| Файл | Что это |
|---|---|
| `LISTING.md` | Готовые тексты листинга: название, описание, обоснование разрешений, раскрытие данных. Копировать в дашборд. |
| `PUBLISH_CHECKLIST.md` | Пошаговый процесс: аккаунт → первая публикация → API-секреты → авто-обновление. |
| `package.sh` | Собирает чистый zip пакета: `bash extension/store/package.sh` → `build/frame-extension-vX.Y.Z.zip`. |
| `assets/tile-440x280.png` | Малый промо-тайл. |
| `assets/marquee-1400x560.png` | Широкий промо-баннер (для фичеринга). |
| `assets/hero-1280x800.png` | Пустая подложка-рамка под скриншот. |
| `screenshots/` | Скриншоты для листинга (1280×800, мин. 1). **TODO: положить 2–3 кадра.** |
| `build/` | Собранные zip (git-ignored, регенерится). |

Перегенерить промо-графику: `python3 scripts/gen-store-assets.py`.
Авто-публикация: тег `ext-v*` → `.github/workflows/publish-extension.yml`.

## Скриншоты — как сделать (быстро)
1. Открой терминал Т-Инвестиций, нажми «F», открой 1–2 индикатора.
2. Скриншоты (1280×800 или 640×400): (а) выпадающий список «F», (б) панель с графиком,
   (в) drawer настроек (⚙). Спрячь баланс счёта, если не хочешь его показывать.
3. Положи в `screenshots/`.
