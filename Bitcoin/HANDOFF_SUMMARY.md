# MOEX Quant — сводка для переноса (опционы + фьючерсы)

Что делали: строили торговые сигналы на данных MOEX FORTS для SBER, GAZP, Si (USD/RUB),
RTS, IMOEX. Данные 2020-2026. Black-76 для опционов на фьючерсы. Walk-forward
train(2020-22)/test(2023-26). Главный найденный edge — futoi (позиционирование физлиц).

================================================================
ЧАСТЬ 1. ОПЦИОННЫЕ ИНДИКАТОРЫ (все)
================================================================

### A. Уровень волатильности
1. **ATM IV** — подразумеваемая волатильность на центральном страйке (Black-76 инверсия из settle-цены). База всего.
2. **Variance swap rate (varswap_iv)** — модельно-свободная IV по всему смайлу (формула VIX). Точнее ATM. На RTS работала лучше всего.
3. **RVI** — официальный индекс волатильности MOEX (опционы на RTS). Наш ATM IV дал corr 0.95 с ним = валидация.
4. **Historical/Realized Vol (RV)** — std дневных лог-доходностей × sqrt(252). Для RU акций именно 252, не 365.

### B. Премия за риск волатильности
5. **VRP = ATM_IV − RV30** — переплата за страх. ROBUST на SBER. На RU: HIGH VRP → bullish (обратно крипте).
6. **VRP_varswap = varswap − RV30** — то же через varswap, чище.

### C. Форма улыбки (skew)
7. **Risk Reversal 25Δ (RR25)** = IV(25Δ call) − IV(25Δ put). Перекос страха. ROBUST на SBER.
8. **Butterfly 25Δ (BF25)** = (IV(25Δc)+IV(25Δp))/2 − IV(ATM). Хвостовой риск. ROBUST на RTS.
9. **Skew slope** — наклон IV по log-страйку вокруг ATM.

### D. Временная структура
10. **Term structure ratio = IV(30d)/IV(90d)** — бэквардация(>1)/контанго(<1). На SBER выглядел сильным но ПЕРЕОБУЧЕНИЕ (провал OOS).
11. IV по тенорам: 7d / 30d / 60d / 90d отдельно.

### E. Греческая агрегация (по всему chain)
12. **GEX (Gamma Exposure)** = Σ OI×гамма×spot²×0.01, знак: дилеры short calls / long puts. На Si/RTS робастный, на SBER провал OOS. Ограничение: на MOEX неизвестно кто net long/short.
13. **Dollar Gamma** = Σ OI×гамма×spot. Магнитные страйки.
14. **Vanna** = ∂delta/∂vol. Squeeze-сетапы.
15. **Charm** = ∂delta/∂time. Pinning к экспирации.
16. **Flip strike** — где гамма меняет знак.

### F. Позиционирование
17. **Put/Call OI ratio** — ОТРАВЛЕН ритейлом на MOEX (80% физлица). Не использовать.
18. **Put/Call volume ratio** — чище чем OI. ROBUST на SBER/Si.
19. **Max Pain** — страйк где продавцы опционов теряют минимум. ROBUST на Si.
20. **OI concentration** — топ страйки = поддержка/сопротивление.

### G. Производные ожидания
21. **Straddle implied move** = (ATM call + ATM put)/F. Ожидаемый диапазон. ROBUST на Si (LOW = bullish).
22. **Breeden-Litzenberger density** — распределение вероятностей из 2-й производной цены call по страйку. Даёт:
    - rn_p_down10 (вероятность падения >10%) — ROBUST на RTS
    - rn_p_up10, rn_skew (асимметрия)
23. **Implied forward** — через put-call parity, F = K + (C−P)/disc.

### ROBUST по активам (train+test оба плюс):
- **SBER**: vrp, rr25, pc_vol_ratio, max_pain, dollar_gamma
- **Si**: straddle_move (LOW), max_pain, pc_vol_ratio, gex, cal-related
- **RTS**: varswap_iv, atm_iv, bf25, gex, rn_p_down10
- **НИ ОДИН не робастен на всех 3** — у каждого актива свой профиль.

### ПРОВАЛИЛИ OOS (выглядели сильными, оказались мусором):
term_structure, GEX на SBER, atm_iv level на SBER, P/C OI ratio.

================================================================
ЧАСТЬ 2. ФЬЮЧЕРСНЫЕ ИНДИКАТОРЫ (все)
================================================================

### A. Позиционирование участников (ГЛАВНЫЙ EDGE)
1. **futoi (FIZ/YUR)** — MOEX публикует позиции физлиц и юрлиц на клиринге FORTS, каждые 5 мин.
   - `fiz_lsr = fiz_long / fiz_short` — главный сигнал.
   - Контрариан: физики в панике (LOW) = дно, в эйфории (HIGH) = топ.
   - На SBER/IMOEX: FIZ LOW → LONG. На Si: физики 93% дней NET LONG USD.
   - На RTS знак ИНВЕРТИРУЕТСЯ.
   - Это COT-аналог в реальном времени. Уникально для MOEX, никто публично не формализовал.
   - Производные: fiz delta (изменение день к дню), yur_lsr, доля участников в лонге.

### B. Временная структура фьючерсов
2. **Базис = (фьючерс − спот)/спот**, годовой = ×365/DTE. SBER median ~10%/год.
   - Бэквардация (базис<0) = стресс → mean revert. Backwardation→bull ROBUST на SBER/GAZP/Si.
   - ВАЖНО единицы: SBER/GAZP фьючерс в копейках×100 (÷100), Si в пунктах×1000 (÷1000), RTS индексные пункты.
3. **Календарный спред = ближний − дальний фьючерс**. MOEX даже листит как инструмент (SRH1SRM1). ROBUST на Si.
4. **Carry residual = базис_годовой − RUSFAR** (ставка). Чистый positioning premium.

### C. Поток и интерес
5. **Open Interest dynamics** — OI×цена комбинации (новые лонги/шорты vs закрытие). Сырой OI бесполезен (ты проверял).
6. **CVD (Cumulative Volume Delta)** — объём по аску минус по биду.
   - Настоящий: из тиков/минуток (sign свечи × volume — прокси).
   - Si CVD20 SHORT: +14% CAGR PF4.53; RTS CVD5 LONG: +15% (2024-26, мало данных).
   - Лучше через Algopack tick-данные.
7. **Volume Profile** — зоны высокой активности = уровни.

### D. Микроструктура (нужны tick/Algopack)
8. **Order Flow Imbalance** — дисбаланс стакана.
9. **Bid-Ask spread dynamics** — расширение = неопределённость.
10. **Aggressive vs passive volume** — BUYSELL флаг в trades (есть, но только текущий день публично).

### E. Smart flow
11. **Block trades** — OFFMARKETDEAL флаг + BUYSELL сторона. Публично ТОЛЬКО текущий день, истории нет (Algopack).

### F. Маржа / стресс
12. **ГО (Гарантийное обеспечение) changes** — биржа поднимает ГО = видит риск раньше рынка. Опережает движения.
    Публично ТОЛЬКО snapshot, истории нет (Algopack). Это потенциально один из лучших сигналов.

### G. Cross-market
13. **Si vs RTS divergence** — рублёвая часть индекса.
14. **Корреляционные сигналы** — резкое падение корреляции связанных активов.
15. **Lead-lag** — Si двигается раньше SBER в кризисы.

================================================================
ЧАСТЬ 3. ЧТО РЕАЛЬНО РАБОТАЕТ (итоги бэктестов)
================================================================

ЛУЧШАЯ СТРАТЕГИЯ (портфель 4 актива):
- STRICT FIZ ≤ 1.2 (паника физиков) + динамическая аллокация + stop 5%
- Активы: SBER, GAZP, Si, RTS
- Вход: fiz_lsr ≤ 1.2; Выход: fiz_lsr ≥ 3.0 ИЛИ VRP ≤ −5 ИЛИ stop 5% ИЛИ 90 дней
- **CAGR 33%, DD 35%, WR 70%, PF 6.56, плюс КАЖДЫЙ год (вкл 2022 +57%)**
- RTS дал больше всех сделок (14), хотя как single-asset худший

Single-asset лучшие:
- SBER FIZ≤1.4: CAGR 17% DD18 WR72 PF5.25 (плюс каждый год)
- Si straddle_move LOW + max_pain L/S: CAGR 25% test DD22
- RTS rn_p_down10 + RVI killswitch: CAGR 17.8% test, 2022 +28%

НЕ РАБОТАЕТ:
- Vol-selling (продажа опционов): честный backtest с bid/ask+ГО+margin call = CAGR 0.3%. Спред съел 97% премии. 40%/год = миф (XIV/Allianz взрывались).
- Большинство опционных греков провалили OOS.
- Микроструктура (базис/спред/CVD-прокси) слабее futoi.

КЛЮЧЕВЫЕ УРОКИ:
1. Главный edge на RU = futoi (позиционирование физлиц), не опционы.
2. У каждого актива свой профиль робастных сигналов.
3. Full-sample edge без walk-forward обманчив (term structure, GEX).
4. RU работает обратно крипте по VRP (HIGH VRP → bullish).
5. Строже сигнал + диверсификация = выше CAGR и WR.
