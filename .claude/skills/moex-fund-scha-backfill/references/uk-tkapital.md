# Т-Капитал (uk_id=3597) — SCHA reference

**TL;DR:** own-site `cdn.t-capital-funds.ru` отдаёт PDF прямым curl (браузер не
нужен). Формат — форма ЦБ 0420502 PDF. ⚠️ **Архивный 2021-формат содержит
`(cid:9)`-артефакт** — был баг «триллион акций», пофикшено в парсере 2026-06-01.

## Откуда данные
- 🟢 **Own-site CDN (основной, Claude curl'ит сам), архив до 2020-09:**
  `https://cdn.t-capital-funds.ru/static/documents/otchet-scha-{ticker}-ДД-ММ-ГГГГ.PDF`
  - Пример: `otchet-scha-tmos-31-05-2026.PDF` (тикер lowercase, дата ДД-ММ-ГГГГ).
  - ⚠️ **Паттерн имени ПЛАВАЕТ по эпохам** — угадыванием URL часть месяцев даёт 403.
    Точные URL брать со страницы фонда `t-capital-funds.ru/documents/mutual_funds/TMOS/`
    (SPA: рендерить в браузере, кнопка «Ещё» догружает историю; каждая ссылка — прямой CDN-URL):
    `otchet-scha-tmos-DD-MM-YYYY.PDF|.pdf` (2022+, регистр расширения случайный) ·
    `4100-tmos-scha-DD-MM-YYYY.pdf` (часть 2025-26, 4100 = № правил ДУ) ·
    `scha-tmos-DD-MM-YYYY.PDF` / `scha-tmos-DDMMYYYY.pdf` (2021-22) ·
    `SCHA_TMOS_DDMMYYYY.PDF` (2020-21) · известная ОПЕЧАТКА УК: `otchet-scha-tmos-31-20-2023.PDF`
    = 31.10.2023 (месяц «20»!).
  - Дыра архива own-site: **2024-10-31 отсутствует** (только e-disclosure).
  - 2020-е: `SCHA_IMB_30092020.pdf` — нестандарт/скан, парсер не берёт; `SCHA_TMOS_31122020` —
    3-колоночный формат, gross не извлекается (намеренный None вместо склейки колонок).
- 🔴 **e-disclosure (card `id=38022`, `type=23`)** — на 2026-07 закрыт интерактивной
  капчей ServicePipe (и локально, и curl; с датацентр-IP прода — TCP RST). Нужен
  человек для капчи. Если доступен: walker собирает fileid → curl `FileLoad.ashx?Fileid=N`.
  - Имена на e-disclosure: «Т-Капитал Облигации»=TBRU, «Т-Капитал Индекс МосБиржи»=TMOS, «…ОФЗ»=TOFZ.
  - ZIP внутри = PDF с кириллическим именем (cp866): `СЧА_Мосбиржа_ДД.ММ.ГГГГ.pdf` / `СЧА_Облигации.pdf`.

## Формат
- **PDF**, форма ЦБ 0420502. Парсер `parse_scha` → стратегия `tables` (header-based) для большинства.
- Дату парсер берёт из тела PDF («по состоянию на 29 октября 2021 г.» / «29.10.2021»); если нет — backfill из имени файла.

## Где нужные поля (строка бумаги в Подразделе 2 «рос. эмитенты» / 3 «иностранные»)
Колонки: `№ | Наименование эмитента | ОГРН(13) | ИНН(10) | ПАО | регномер выпуска | ISIN | Категория | КОЛИЧЕСТВО | СТОИМОСТЬ ₽ | биржа | уровень`.
- **positions = «Количество»** (предпоследнее число), **value = «Стоимость»** (последнее).
- ⚠️ ОГРН (13 цифр) и ИНН (10) идут РАНЬШЕ количества — НЕ перепутать.

## Трудности и как избежать
- 🐞 **`(cid:9)`-артефакт в архивном 2021-формате (ИСПРАВЛЕНО 2026-06-01, commit `8a75b6f`).**
  В сен/окт-2021 разделитель разрядов рендерится неотображённым глифом → pdfplumber
  выдаёт `1(cid:9)069(cid:9)930` вместо `1 069 930`. Два провала сразу:
  1. rowwise-фильтр `any(isalpha)` отбрасывал ячейку (в `(cid:9)` есть буквы c,i,d) →
     брал ОГРН/ИНН за qty/value → **«1 027 700 132 195 акций Сбербанка»** (это ОГРН!).
  2. `_parse_int` срезал буквы, но ОСТАВЛЯЛ цифру 9 из `cid:9` → `1(cid:9)069(cid:9)930`=`190699930`.
  **Фикс:** `re.sub(r"\(cid:\d+\)","")` в `_parse_int`/`_parse_float`/`_norm` (покрывает все стратегии).
  **При импорте старых Т-Кап PDF — спот-чек:** Сбербанк должен давать цену 300-400₽
  (value/positions), а не «триллион штук». Спайк на графике актива в 2021 = этот баг.
- Имя эмитента переносится на следующую строку («Сбербанк России») — парсер переживает (имя из MOEX по ISIN).
- Глобальный дедуп по ISIN обязателен (был баг TBRU/TMOS 2024-06-28: дубль таблиц → Σвесов=50%).
  С 2026-07-18 дедуп идёт ДО выбора стратегии (иначе раздутый счётчик tables глушил rowwise-апгрейд).
- 🐞 Старый лейаут 2020-21: у строк хвостовая колонка «доля, %» — парсер отсекает
  (иначе процент шёл за стоимость); gross там бывает без копеек и клеится с «100,08»
  (обработано в `_find_gross_assets_text`). Пофикшено 2026-07-18 (PR #697).
