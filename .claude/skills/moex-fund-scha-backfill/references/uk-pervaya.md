# Первая / Сбер (uk_id=34) — SCHA reference

**TL;DR:** own-site `first-am.ru` — ЛУЧШИЙ источник, прямой curl PDF (e-disclosure
банит сервер по IP). ⚠️ БПИФ и ОПИФ — РАЗНЫЕ пути на сайте.

## Откуда данные
- 🟢 **БПИФ → first-am.ru (Claude curl'ит сам):**
  - Индекс: `https://first-am.ru/individuals/etf/{slug}/documents`
  - Файл: `https://first-am.ru/download/{doc_id}/<кириллическое имя>.PDF` — нужен ПОЛНЫЙ
    путь с именем (bare `/download/{id}/` → 404). Кириллицу через
    `urllib.parse.quote(path, safe=":/?&=%#,-._~+")`.
  - SCHA = ссылки, где имя содержит `Справка о стоимости чистых активов_за_<месяц>_<год>г`.
    Дедуп по (год,месяц), первая ссылка = свежайшая ревизия. Архив с ~2023-08.
- 🟢 **ОПИФ (акционерные) → first-am.ru под ДРУГИМ путём** `/individuals/fund/{slug}` (НЕ `/etf/`!).
  **НЕТ на Интерфаксе** (карточка 6731 = только БПИФ/ЗПИФ).
- 🔵 **SAFE → e-disclosure** (на first-am отсутствует): card `6731`, имя
  «Первая – Фонд Консервативный» (isin RU000A1035N9).

## Формат
- **PDF**, форма 0420502, многостраничный **35-стр layout** (шапка таблицы и строки
  данных на разных страницах). Парсер `parse_scha` → стратегия `tables_rowwise`.

## Где нужные поля
rowwise-инвариант: **количество и стоимость = два ПОСЛЕДНИХ числа строки**
(ОГРН/ИНН/регномер/дата погашения раньше; биржа + «уровень 1» — текст в хвосте).
ISIN может быть разрезан переносом (`RU0009029\n540`) — склеивается.

## Трудности и как избежать
- e-disclosure банит сервер по IP (403, ServicePipe-челлендж) → используй first-am.ru (curl)
  или локальный браузер для walker'а.
- БПИФ авто-матчатся по `funds.isin_pif` из метаданных PDF (заполнены).
  ОПИФ — `isin_pif` НЕ извлекается → матч по тикеру в имени файла (`OPIF-43_ГГГГ-ММ-ДД.pdf`).
- Сверено: SBMX акции 42-51, суммы точно сходятся с субтоталом формы
  (Сбер 8 305 478 шт, Газпром 15 792 660 — точное совпадение). Бага ×1000 нет.
